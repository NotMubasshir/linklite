# LinkLite — Shorten URLs. Share Smarter.

LinkLite is a fast, lightweight, and modern URL shortener web application designed for seamless link management, custom alias creation, password protection, and real-time click analytics.

---

## Features

* **Instant Link Shortening:** Quickly convert long, messy URLs into clean, manageable links.
* **Custom Aliases & Protection:** Set custom link aliases, expiration dates, and password protection.
* **QR Code Generation:** Automatically generates downloadable QR codes for every shortened URL.
* **Analytics Dashboard:** Monitor total links, click counts, today's activity, traffic source referrers, and click trends over time using interactive charts.
* **Dark / Light Mode:** Built-in theme switcher for comfortable viewing day or night.
* **Local Data & Export:** Search, filter, and sort your link history, or export your link data to CSV.
